ABHINANDAN CHATTERJEE — PERSONAL WEBSITE
=========================================

Files
- index.html: complete responsive one-page website.

Preview
- Open index.html in any modern browser.

Before publishing
1. Replace hello@example.com in index.html with a public email address, or remove the contact button.
2. Add your chosen public social-media links.
3. Review the biography and project descriptions for accuracy.
4. If you add a portrait, use an image you have permission to publish.
5. Publish using a static website host such as GitHub Pages, Netlify, or Cloudflare Pages.

Design direction
- A blend of Statesman (navy and gold), Renaissance (ivory, saffron, maroon), and Personal Republic (civilisational accents with a modern editorial layout).
- Responsive on mobile and desktop.
- No external libraries or build process required.
